# 游戏按钮编号

以后指定“按钮 1”到“按钮 9”，对应 `styles/button-system.css` 中的 `.button-1` 到 `.button-9`。编号决定颜色和边框；宽度、高度可随所在面板调整。

| 编号 | 样式 | 当前用途 |
| --- | --- | --- |
| 按钮 1 | 橙金渐变，深色字 | 开始、确认出售、发帖分享等主操作 |
| 按钮 2 | 深灰底，浅色字 | 取消、返回等次操作 |
| 按钮 3 | 深棕底，金色边框 | 确认天赋、普通招募、需要强调但非主操作的入口 |
| 按钮 4 | 亮金渐变，深色字 | 看广告自选天赋、看广告招募 |
| 按钮 5 | 深红底，浅红边框 | 出售、危险操作入口 |
| 按钮 6 | 深色卡片，选中时金边 | 天赋、球员、战术选择卡 |
| 按钮 7 | 深色金边小按钮 | 返回主页、查看详情、图鉴入口 |
| 按钮 8 | 深色金边方形图标 | 弹窗关闭按钮 |
| 按钮 9 | 深色页签，选中时橙金色 | 排行榜、商店等切换页签 |

示例：`<button class="button-3">确认天赋</button>`。广告图标统一使用 `assets/reward-video-icon.svg`。
