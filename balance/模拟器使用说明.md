# 正常游玩数值模拟器

默认按正常玩家流程测试。低阶novice／无成长，中阶ordinary／半成长，高阶expert／满局外成长。全部从空阵容开始，球员、训练、装备和事件奖励按实际经济与概率获取，直到最终死亡。低、中阶关闭广告，高阶按真实次数限制观看奖励广告、自选天赋与5星词条，并使用一次死亡恢复。

完整约定见根目录[AGENTS.md](../AGENTS.md)；已有结果见[本次数值参考](../docs/balance/2026-10-11/README.md)。高阶追求最佳羁绊，但AI决策不是全局最优证明。

## 主参考命令

```powershell
$snapshot = 'docs/balance/YYYY-MM-DD-更新/正常游玩.json'
npm run balance:reference -- --count 100 --out $snapshot
$env:BALANCE_NATURAL_SNAPSHOT = $snapshot
npm run balance:reference:test
```

默认每档100局，固定种子81101起，主参考默认单局600秒、每战前500次操作；用`--rules-version 6`复测更新前玩法，`--rules-version 8`测试词条与天赋更新，`--rules-version 9`测试关卡微调；可用`--count`调整样本数、`--max-actions`与`--max-ms`调整操作／时间边界，`--concurrency`设置每档并行数（建议4，三档同时运行）。测试边界不是失败，截断样本必须单列。正常输出包含JSON、逐关CSV与静态HTML。完整回归测试与批量模拟分开运行，避免内存竞争。

曲线每局每关只取首次开战前的面板OVR；显示到达玩家中位数、对手OVR、到达人数／比例与玩家范围。玩家死亡后不补数据，后期不能忽略幸存者偏差。已有日期目录保持原样，新版本写新目录。

本轮新旧对比保存于 `docs/balance/2026-10-11-词条天赋更新/`，旧、新子目录各100局／档。两边完成后运行 `npm run balance:compare`，生成对比报告、逐局差值、同关OVR与叠加页面。高阶广告策略同步应用于两边；旧30局无广告参考保留，不能直接把广告口径变化算作更新收益。

后续关卡微调另存 `docs/balance/2026-10-11-关卡微调/`，通过 `npm run balance:tuning:compare` 与已验收的规则6、8数据对比。复用历史基线时核对旧曲线未变、种子、成长、策略、广告与边界一致，不覆盖历史快照。

## 单局与完整重放日志

后续60关节点调整使用规则14，按用户要求本次不运行模拟或测试套件。`npm run balance:endless:node` 只生成新对手曲线和静态对比页面，引用规则13既有玩家轨迹（低、中100局，高阶90局）；不能标为规则14实测结果。输出在 `docs/balance/2026-10-12-无尽60关节点/`，前20关不变，旧页面保留。

2026-10-12无尽难度微调使用规则13，仅降低第11关起的对手属性，主线1—10关保持不变。输出在 `docs/balance/2026-10-12-无尽难度微调/`；按用户后续要求，只重测新版低、中各100局，高阶90局；复用上一轮规则12相同种子记录，同种子、同策略、同广告与全部测试边界。使用 `npm run balance:endless:compare` 生成对比页面与报告，逐种子核对前10关轨迹。旧页面、统计与源码快照保持原样。

```powershell
$snapshot = 'docs/balance/2026-10-12-无尽难度微调/新版/正常游玩.json'
npm run balance:reference -- --count 100 --high-count 90 --rules-version 13 --date 2026-10-12 --concurrency 8 --max-ms 1800000 --out $snapshot
$env:BALANCE_NATURAL_SNAPSHOT = $snapshot
npm run balance:reference:test
npm run balance:endless:compare
```

后端保持规则11未部署，规则13的回放验证仅使用浏览器核心与本地权威校验器模拟；发布前仍须完成配套后端兼容验收。

2026-10-12球员与羁绊更新对比在 `docs/balance/2026-10-12-球员羁绊更新/`。用户明确要求仅使用`--rules-version 12`重测，每档100局；旧版引用规则9既有记录。`npm run balance:roster:compare`生成新版对比页面与报告，并注明两次测试器覆盖差异，不能把全部变化仅归因于本次球员／羁绊更新。高阶新增SSR全部解锁但仍正常招募，包含球员商店购买／刷新和可获收益的重复徽章广告。规则12后端尚未部署，只做浏览器核心与本地权威校验器模拟，不能称为生产后端验收。本轮每档并发8局，单局时间边界1800秒（历史600秒）；最终必须核对实际截断数。

```powershell
npm run balance:run -- --seed 10001 --policy expert --max-stage 1000 --out artifacts/balance/run
npm run balance:smoke -- --count 20 --out artifacts/balance/smoke
npm run balance:replay -- --file artifacts/balance/run/expert-10001.json
npm run balance:validate -- --file artifacts/balance/run/expert-10001.json
npm run balance:test
```

`cli.cjs`使用独立Worker和运行边界；`runner.cjs`记录真实核心操作、战斗与状态，重放检查种子、操作结果和最终状态。浏览器全局核心与云端权威重放分别核对，不能仅看Node实现自身重复运行。

`engine.cjs`创建合法初始状态；`driver.cjs`枚举可执行操作并检查资源及阵容；`policies.cjs`实现三档策略；`objectives.cjs`定义高手追求的路线。高手仅观察公开信息及交手后学到的战术，不读取未来随机结果。

## 辅助压力测试

```powershell
npm run balance:reference:pressure -- --out docs/balance/YYYY-MM-DD/pressure --compare docs/balance/2026-10-11/baseline.json
```

预置满配、每关满训和免费强化只用于检查极端叠加，必须明确标为压力场景。旧压力图第一关673 OVR与474关交点不能用作正常成长结论。

历史批量工具`suite.cjs`、`analyze.cjs`和`report-round2.cjs`保留为代码工具；不要把历史输出、缺失原始日志的旧结论当作新版本验收结果。
