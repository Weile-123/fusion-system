# 我的球星融合系统

一款以 NBA 球星能力组合为主题的移动端 H5 Roguelike 游戏原型。每局招募不同球星，把他们安排到六个能力槽，融合成一名球员，依靠阵容、羁绊、训练和赛前策略挑战逐关增强的对手。

> 当前为可玩的第四版原型，使用策划设定的静态球星数据与自动模拟对战；尚未上线，也没有官方 NBA 授权或关联。

## 玩法循环

1. 从三个随机开局天赋中选择一个。
2. 每轮四选一招募球星，填满三分、中投、突破、控球、篮下、防守六个能力槽。
3. 调整首发与备战席，利用球星专属天赋、升星和羁绊提升融合球员能力。
4. 使用对战奖金训练球星、购买强化或装备，并选择克制对手的单挑策略。
5. 自动进行半场 1v1，查看比分、关键回合和奖金结算。失败消耗士气，可整备后重试；完成十关后可进入无尽挑战。

首页与局内分开：招募和商店在游戏内，传奇档案与球星图鉴从首页进入。界面采用深炭黑与橙金配色，球星卡按稀有度区分颜色。

## 当前已实现

| 系统 | 当前内容 |
| --- | --- |
| 构筑 | 110 名基础球员、8 张 SSR 异名卡、80 组羁绊、六项属性与六能力槽、备战席、换位与重复升星 |
| 成长 | 随关卡提升的招募等级概率、可触发的球员专属天赋、训练、赛前强化、装备、备战席扩容、奖金管理 |
| 对战 | 赛前策略克制、按随机种子可复现的自动单挑、战报、士气、十关主线与无尽模式 |
| 档案 | 传奇点、累计战绩、最佳关卡与已发现球星图鉴 |
| 存档 | 活动容器优先使用 `ColorboxAI.storage`；直接打开本地页面时使用 IndexedDB 保存进度 |

指定球星商店、随机事件与排行榜仍在规划中。激励广告现用于每段旅程一次的 S 级球员四选一；传奇点已经可用于永久升级与传奇球衣解锁。

## 本地运行

项目使用 React 与 Vite。首次运行先安装依赖，然后启动开发服务器：

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址即可试玩。存档保存在当前浏览器；更换浏览器或清除站点数据后，可能无法继续原进度。生产构建使用 `npm run build`，输出目录为 `dist/`。

游戏没有云后端，也不需要登录。活动容器内的存档接入按项目提供的 Colorbox 存储技能实现；广告和排行榜接入前也需遵循相应技能约束。

## 项目结构

```text
index.html            Vite 页面入口
src/
  App.jsx             React 应用外壳与启动状态
  react-screens.jsx   React 页面与公共组件
  runtime-loader.js   游戏数据、规则和存档模块加载器
h5/
  game-core.js        球星数据、融合、经济、对战和关卡规则
  game-ui.js          游戏状态与交互控制器
  assets/             原创虚构篮球人物概念插画
tests/
  game-core.test.cjs  核心流程与规则测试
  storage-adapter.test.cjs  本地与活动容器存档测试
```

运行测试：

```bash
npm test
```

当前自动测试覆盖球员等级与属性区间、羁绊网络与经济效果、开局招募、备战席、训练和升星上限、奖励防重复领取、策略克制、十关流程及存档恢复。实际手机上的视觉和点击体验仍需试玩。
