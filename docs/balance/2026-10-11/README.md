## 三档玩家怎样正常游玩

|档位|账号局外成长|局内行为|
|---|---|---|
|低阶|无升级|新手策略：优先基础属性，较少统筹羁绊与经济|
|中阶|各项升至上限约一半|普通策略：考虑位置、重复升星、装备、羁绊和收益|
|高阶|局外升级满级，球衣／传奇装备／天赋解锁池全部开放|高手策略：目标羁绊构筑，统筹招募、训练、装备、经济和续航，利用已交手对手的战术信息|

三档均从正式游戏第一关开始，只获得正常发放的开局奖金和免费招募。球衣、装备、球员只是可抽取／购买，不会因解锁而直接持有。不直接写入阵容，不补奖金，不免费满星满训，不强制触发事件，不偷看未交手对手的隐藏策略；广告关闭。

高阶“满配”是账号局外进度及局内追求的成型目标，第一关并未拥有最终构筑。AI策略不等于人类全局最优决策，本基线比较三种明确策略的实际流程，不承诺找到所有玩法的最高通关能力。

## 曲线怎样取样

- 每档30局，同一组种子81101—81130；招募、购物、训练、事件、战斗和结算均调用实际核心。
- 每局每关取第一次开战前的面板OVR。失败重试继续正常游玩，但不重复计入同关统计。
- 绿线为到达该关玩家OVR的中位数，红线为对手面板OVR；同时保存到达人数／比例与玩家OVR最小、最大值。
- 玩家死亡后停止，后续不补数据、不虚构训练、不复活继续跑；无人到达的关卡不画玩家线。
- 后期数据只来自存活玩家，存在幸存者偏差，不能把少数幸运样本当作普遍表现。
- 单局边界：1000关、2000场战斗、30000次操作、180秒。达到边界记为截断，不当作死亡；若有截断，止步分布不能当作最终上限。

原始结果保存于 `natural-baseline.json` 和 `natural-curves.csv`；各局保留种子、停止原因、每关OVR、奖金和羁绊数量。各档首局核对浏览器核心与云端权威回放。

## 本次正常流程结果

90局全部正常游玩到死亡，执行错误0、截断0。各档首局的浏览器核心与云端权威回放一致；19项自动验证全部通过。

|档位|样本数|第一关OVR中位数（最小—最大）|主线通关局数|已通过关卡中位数|样本已通过最高关卡|
|---|---:|---|---:|---:|---:|
|低阶|30|85（78—108）|14 / 30|8.5|33|
|中阶|30|86（78—110）|20 / 30|19|38|
|高阶|30|90（84—115）|27 / 30|49.5|63|

对手第一关为64 OVR。高阶第一关实际首次开战OVR中位数为90，样本最高115，并未达到旧图的673。

第50关有18 / 30名高阶玩家到达，首次开战OVR中位数428.5、范围373—493，对手501。最后1名高阶样本到第64关时为514 OVR，对手588，最终未通过，因此样本最高已通过为63而非64。低阶、中阶无人到达50关，不为它们生成50关玩家数据。

这些结果只描述这90局策略样本。63不是游戏理论上限，30局也不足以证明所有高阶玩家的止步范围；后续扩大样本时，应同时比较同关到达人数和OVR分布，不能仅比较最高一局。

## 后续版本重跑

`npm run balance:reference -- --out docs/balance/YYYY-MM-DD/natural-baseline.json`输出新日期快照，保留旧数据。比较主线通关数、止步分布、同关OVR与到达人数，尤其关注高阶在正常奖金及抽取条件下成型后是否持续碾压。

`npm run balance:reference:pressure -- --out docs/balance/YYYY-MM-DD/pressure --compare docs/balance/2026-10-11/baseline.json`辅助检查极端叠加，与自然成长分开解读。

`npm run balance:reference:test`验证数据和前后端一致性。版本更新后将测试快照指向新日期，不覆盖旧基线。
