# 当前版本难度曲线参考基线

> 历史辅助压力测试。预置成型配置不代表正常成长；实际游玩结果以[正常流程基线](README.md)为准，474关交点不可解读为真实玩家止步关卡。

日期：2026-10-11；数值规则版本：6。此次测试直接调用仓库中的实际游戏核心，没有另写一套近似的 OVR 或胜负公式。

查看 [压力上界曲线](pressure-upper.html)（浏览器打开本地文件即可）、[完整数据与源码哈希](baseline.json)、[逐关 CSV](curves.csv)。历史报告保留在 [BALANCE_REPORT.md](../../../BALANCE_REPORT.md)，本次结果不覆盖旧数据。

## 需要关注的结论

**已成型的高阶满配构筑明显超过当前中后期对手强度，不能仅凭普通招募流程的通关情况认定数值安全。** 第50关高阶常驻 OVR 为2196，对手实际 OVR 为501，约4.38倍；第100关为3350对855，约3.92倍。该构筑不含赛前强化和事件加成。

这不是“自然玩家一定能达到该战力”的结论：曲线每关都按对应档位补齐训练和星级，满配预先持有全部球衣、装备、目标球员，不核算这些资产的获取概率、奖金和训练费用。它用于检查成型后的数值压力。自然获取流程另测，结果分别记录，不能把两类数据混用。

常驻配置最后一次在面板 OVR 上不低于对手的关卡：低阶22、中阶41、高阶474。加入免费买满本场强化和一次性事件的宽松压力上界后，分别为38、108、565。这些数字是曲线交点，不是能够连续通关的承诺。

## 当前机制与上限

- 128名球员、100条羁绊、36个随机事件；融合面板6个主力位置。羁绊按拥有的球员身份计算，备战席计入，同一球员普通版与SSR不重复计人数；随机事件的指定人物必须在融合面板，备战席不算。
- 前10关星级最高3星、训练最高3级；无尽模式S/SSR最高10星，C/B/A最高20星；无尽训练上限等于当前关卡。**无尽关卡无限增长，因此没有一个固定的全游戏最高OVR**，只能给定关卡、配置、资源后求上限。
- 普通球员每颗额外星级增加10%六维属性、每级训练增加3%；SSR为20%与4%。满级训练团队再加3个百分点；球星工坊还能加星级2个百分点、训练1个百分点。此处是基础属性增长，不是直接给OVR加固定点数。
- 局外升级项目全部买满共16920传奇点，不包含解锁抽取及球衣、传奇装备解锁等另付费用。满级备战席一般初始11席，豪华轮换14席；球星工坊初始10席。扩容上限与初始容量并非总是相同，模拟保留合法初始容量。
- 装备最多6件、各装备槽位一件；普通未装备收藏容量最高10件，球衣不占该容量。27件球衣可以全收藏，未装备球衣效果按35%计，装备后的球衣按52.5%计。
- 五维加成超过30%的部分折半增长，**不是封顶30%**。羁绊链同时满足时多层均可生效，更衣室凝聚再放大羁绊加成，因此需检查叠加压力。
- 每种赛前强化前10关最多买2次、无尽每关最多10次，战斗后消耗；全部8种在无尽买满为80件，当前高阶候选商品标价总计550奖金，另外还可能需要商店刷新费。压力上界不扣奖金，不代表每关正常购买得起。
- 事件每局每条最多触发一次，有条件、概率与冷却；当前版本不再使用旧版每维15%的事件加成上限。把所有加属性事件最大收益相加，可得到投射27%、终结27%、创造20%、外线限制32%、护框22%的有限宽松上界。该上界忽略轮换触发条件、失败条件、触发顺序及冷却，前期尤其不能视为实际可获得值；不重复加事件赠送球衣。
- 对手前10关目标为64、70、78、86、90、92、94、96、99、103；11—20关按旧二次增长；21—50关从126按指数增长到约500；50关后为 `500×(1+(关卡-50)/125)×exp(0.004×(关卡-50))`。实际五维取整与递增校准会造成小幅差异，因此曲线调用 `opponent()`，第50关实际为501而非直接写500。
- 曲线统一使用无战术的面板 `fused(run).rating`，对手同样使用面板OVR。真实战斗还包括五维分布、战术克制、专属动作、装备效果、命中与失误随机性；OVR较高不保证必胜。

## 验证口径

三套曲线各1000点；15个关键关卡，每档独立300场真实战斗，共13500场。战斗种子72101—72400，模型配置种子61101，战术仅参考本方可见投射／终结五维，不偷看对手隐藏策略。页面显示样本胜率和95% Wilson区间。

每场都从该关配置重新开始，故样本胜率是**到达该关后的单场胜率**，不是从第1关一路打到此关的概率。当前模型没有因上一场失败导致死亡而停止曲线，远期点仅表示压力测试。

第50关低／中／高常驻配置样本胜率分别为1.0%、10.0%、100.0%；高阶第100关为99.0%。其中100.0%仅代表300场样本全部获胜，其95%区间下界约98.7%，不表示游戏机制保证必胜。

全部3000点检查了阵容容量、星级、训练、装备槽位、有限数值、对手递增；规则断点核对了浏览器全局核心与云端核心的相同结果；固定种子战斗可重复。静态页面脚本解析、内嵌数据及所有范围／坐标／配置切换的绘图和悬停逻辑已验证。`npm run balance:reference:test`共16项通过；独立重跑全部天赋搜索的45个比较点完全一致。实际浏览器视觉验收未自动截图。

## 后续版本如何参考

1. 保留本目录作为不可覆盖的历史基线。更新压力模型后输出到新日期目录：`npm run balance:reference:pressure -- --out docs/balance/YYYY-MM-DD/pressure --compare docs/balance/2026-10-11/baseline.json`。正常游玩测试以README中的命令为准。
2. 查看生成的 `comparison.json`、两版曲线、关键关卡玩家／对手比值和交点变化；`frozenPlayerAfter`使用旧候选配置计算新版本OVR，`playerAfter`为重新搜索后的结果，必须同时检查候选阵容变化。
3. 跑 `npm run balance:reference:natural -- --out docs/balance/YYYY-MM-DD/natural-runs.json` 补充真实招募、奖金、训练、事件流程，不覆盖本基线。
4. 跑 `npm run balance:reference:test`。新增球员、羁绊、装备、事件或成长项后尤其检查满配模型、临时加成和前／后端核心是否同步。
5. 上线前明确接受的难度目标：低／中预计止步范围、高阶成型后可挑战的范围、最大玩家／对手比值、强化购买可持续性。当前结果揭示了风险，但**没有自动修改游戏难度，也不能仅因测试通过就认定平衡合理**。

原始数据保留源码SHA-256、规则版本、配置、搜索次数、逐关最优候选编号、战斗种子。OVR曲线允许重跑精确比较；自然流程的时间耗尽样本应标为截断而不是失败。
