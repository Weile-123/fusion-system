## 防作弊实现与范围

- 即时开局采用本地固定种子，再由服务器绑定并禁止变更；服务器按已验证历史检查天赋解锁及局外加成消费。拒绝超过已验证传奇点的升级、未知字段、退回已记录升级或移除已记录球衣。种子选择的防作弊限制及队列行为详见 `background-sync-2026-10-08.md`。
- 前端记录合法操作，服务器从自己保存的状态重放招募、训练、商店、换位、十连和阶段推进。客户端阵容、属性、奖金、随机数和直接声明的 OVR 不参与成绩计算。
- 每次提交绑定局标识、登录用户、递增序号和请求摘要；数据库原子地提交状态及榜单结果，拒绝改写既有步骤，支持同一请求重试。
- 旧局没有完整操作记录，只能继续本地游戏；新开局才使用验证协议。旧存档中的天赋、升级及球衣不能仅凭本地字段导入云端可信进度，若缺少对应云端验证历史，本局保留本地玩法并显示原因。这是此次防作弊上线需要明确接受的兼容性变化。
- 局外加成在开局校验、锁定；进行中的局不因局外购买新球衣而改变已锁定的球衣池，新解锁内容从下一局生效。
- 在线球衣随机解锁由服务端生成并原子记账，带持久化请求标识；响应丢失后重试返回原球衣，不重复收费。开局拒绝客户端直接新增球衣集合。无云 SDK 的本地预览仍允许本地解锁，其结果不能直接导入可信榜单。
- 广告与编辑器仍依据原生 SDK 的客户端成功回调。分享按既有产品约定在编辑器打开回调发一次 100 点；服务器要求至少完成一场有效对战且每局仅一次，空局不能刷奖励。但原生契约没有提供服务器独立验签凭据，不能声称服务器已证明看完广告或实际发布帖子。重放校验也不防止利用公开种子离线计算最优操作。
