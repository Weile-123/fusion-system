# 前端发布审核声明

版本：1.3.0；核查日期：2026-10-12。

针对“引用了非批准域名 www.nba.com”的审核提示，我们核查了源码、构建产物及调用路径。原发布包中的相关网址来自 `h5/game-data.js` 羁绊数据的 `history.source` 字段，仅记录篮球历史资料出处。该字段未用于网络请求、图片或字体加载、页面跳转，也没有用于远程执行代码。游戏所需的球员、羁绊及效果数据均已包含在本地代码中，不依赖访问这些资料网站。

因此，本次提示对应的是静态资料出处字符串，并非实际的未批准域名请求。原包确实包含这些网址；为满足发布域名门禁，已在前端构建阶段移除23条不参与运行的历史资料出处链接，涉及 `www.nba.com`、`api-hub.nba.com` 和 `cdn.nba.com`。源码中的资料记录继续保留用于开发核查，不随前端发布包交付。

当前发布包为 [1.3.1前端发布包-常驻滚动条.zip](../../artifacts/前端上线准备/2026-10-13-1.3.1/前端发布包-常驻滚动条.zip)，包含本次域名修复及后续SSR概率、100抽保底、广告计数及奖金明细滚动条更新。已检查完整ZIP内所有文件，未发现 `nba.com` 字符串；ZIP内容与本次dist逐文件校验一致。域名修复时生产构建成功，相关81项回归测试全部通过，并对构建前后的完整游戏数据进行比较：除移除历史资料出处字段外，数据保持一致。后续最新验收见[广告招募保底规则16上线验收](广告招募保底规则16上线验收.md)。

另外，包内SVG的 `http://www.w3.org/2000/svg` 是XML命名空间标识，不会因此产生网络访问；本地字体许可证中的网址是版权和许可文本，字体通过包内相对路径加载。这些标识及版权文本需要保留。实际联网服务仍使用游戏云端接口和反馈接口；此声明不代表其他域名已获得平台批准，最终以平台配置和审核结果为准。

域名修复本身仅调整前端构建产物；后续SSR和广告计数更新的玩法、存档及后端变更见其独立验收记录。
