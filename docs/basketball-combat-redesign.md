# 球星融合新战斗设计：独立战力维度与 11 分制单挑

状态：**已接入正式游戏，首版平衡**。更新日期：2026-09-24。数值结构按“基础属性 → 槽位评分 → 融合战力 → 技能修正”分层；比赛采用本游戏的**融合球员对单名球星、逐回合自动单挑、先到 11 分且领先 2 分**规则。

## 1. 设计目标与边界

1. 球员卡上的三分、中投、突破、控球、篮下、防守继续表达球员特点、推荐槽位、升星和训练价值。
2. 六张上场卡各占一个能力槽，组成**同一名融合球员**。槽位评分决定融合球员的五项独立战力维度；技能和羁绊不提高卡面六项属性。
3. 五维驱动回合中的失误、出手质量、命中和防守。没有三阶段、三局两胜或额外的回合积分。
4. 保留三种赛前策略、现有克制环、2 分远投/1 分中近投、双方交替进攻、11 分领先 2 分及 15 分封顶。
5. 招募等级、球员基础属性、经济、训练与升星规则暂不随战斗框架改变。技能、羁绊、装备和临时强化均作用于战力或经济层。

## 2. 数值层与计算顺序

```text
球员六项基础属性
  → 升星/训练的基础属性成长
  → 六个能力槽各自的槽位评分
  → 融合球员五项战力维度
  → 技能/羁绊/装备/强化/开局天赋的五维加成
  → 赛前策略与克制的维度百分比
  → 每回合：选出手区域 → 判失误 → 判命中 → 记 1/2 分 → 交换球权
  → 达成 11 分领先 2 分或 15 分封顶 → 奖金与战报
```

只有升星和训练能提高球员六项属性。技能、羁绊、装备、赛前强化和开局战斗天赋在五维生成**之后**生效，不回写球员属性或槽位评分。槽位评分和五维计算保留浮点数，六项融合属性和界面展示取整。

## 3. 六个能力槽评分

设升星、训练和基础装备后的球员六项值为 `三分 3P、中投 MID、突破 DRV、控球 HDL、篮下 INS、防守 DEF`。每个槽位只读取占该槽的球员：

| 槽位 | 评分公式 | 设计用途 |
| --- | --- | --- |
| 三分 | `0.65×3P + 0.20×MID + 0.15×HDL` | 接球与持球远投 |
| 中投 | `0.55×MID + 0.25×DRV + 0.20×3P` | 急停与中距离创造 |
| 突破 | `0.55×DRV + 0.25×HDL + 0.20×INS` | 过人和杀入禁区 |
| 控球 | `0.55×HDL + 0.25×DRV + 0.20×MID` | 运球稳定与起手创造 |
| 篮下 | `0.60×INS + 0.25×DRV + 0.15×DEF` | 近筐终结与身体对抗 |
| 防守 | `0.60×DEF + 0.25×INS + 0.15×HDL` | 对位压迫与护框 |

这些是**槽位评分**，与球员原始单项不同。同一球员换槽会改变评分以及其后生成的五维。球员技能的触发条件仍由当前所在槽位判定，效果只进入五维。六槽不满时不能开始比赛。

## 4. 融合球员的独立战力五维

设六槽评分为 `T=三分、M=中投、D=突破、H=控球、I=篮下、F=防守`，得到：

| 战力维度 | 公式 | 回合用途 |
| --- | --- | --- |
| **投射威胁** `shooting` | `0.50T + 0.35M + 0.15H` | 三分和中投的进攻底盘 |
| **持球创造** `creation` | `0.50H + 0.30D + 0.20M` | 减少失误、改善出手空间 |
| **禁区终结** `finishing` | `0.50I + 0.35D + 0.15M` | 突破后的近筐得分 |
| **外线限制** `perimeterStop` | `0.50F + 0.30H + 0.20D` | 防三分、干扰运球与急停 |
| **护框强度** `rimStop` | `0.50F + 0.35I + 0.15D` | 防突破与篮下得分 |

五维不直接显示为三分、中投等球员属性；每一维同时受多个槽影响。例如防守槽放入强防守球员会提高两项防守维度，但控球、篮下和突破槽也会改变防守表现。三分槽强不自动等于整名融合球员有高命中率，仍需持球创造和中投槽支撑。

五维效果统一采用**百分点相加、一次乘算**：

```text
战力维度 = 基础五维 × [1 + clamp(技能% + 羁绊% + 装备% + 强化% + 天赋% + 战术%, -30%, +40%)]
```

这是首次平衡的限幅，防止成长系统、SSR 与高阶羁绊叠加后把命中率推到恒定上限。训练和升星增加基础值，不占这 ±30%/40% 的百分比预算。经济类效果独立结算，不占战力限幅。

## 5. 策略只影响整场打法，不切换赛制

保留目前的克制环：**外线拉开 → 护框收缩 → 突破冲筐 → 外线拉开**。双方赛前各选一项；对手倾向可在开战前看到，准确情报可由球探或效果提供。首版策略参数：

| 策略 | 出手分布：三分/中投/篮下 | 五维效果 | 克制成功时 |
| --- | --- | --- | --- |
| 外线拉开 | 57% / 22% / 21% | 投射威胁 +12%，护框强度 -4% | 投射威胁再 +6% |
| 突破冲筐 | 17% / 24% / 59% | 禁区终结 +12%，外线限制 -4% | 禁区终结再 +6% |
| 护框收缩 | 35% / 30% / 35% | 护框强度 +12%，投射威胁 -4% | 护框强度再 +6% |

策略加成和技能等五维效果一起相加后限幅。克制只增加被强化的维度，不给“直接 +8% 命中”这一难解释的额外项。每个回合仍按策略的出手分布独立选择区域；强队选错策略仍有取胜机会。

## 6. 单回合命中模型

为避免训练后数值膨胀使固定差值失效，用相对差定义对抗优势：

```text
edge(A, B) = clamp((A-B) / max(80, (A+B)/2), -0.5, +0.5)
```

攻防双方各自使用五维，另保留槽位特色。某次出手的攻防强度：

| 出手 | 进攻 `attack` | 防守 `guard` | 基础命中率 | 得分 |
| --- | --- | --- | ---: | ---: |
| 三分 | `0.80×投射威胁 + 0.20×三分槽评分` | `0.80×外线限制 + 0.20×护框强度` | 29% | 2 |
| 中投 | `0.80×投射威胁 + 0.20×中投槽评分` | `0.60×外线限制 + 0.40×护框强度` | 46% | 1 |
| 篮下 | `0.80×禁区终结 + 0.20×篮下槽评分` | `0.20×外线限制 + 0.80×护框强度` | 55% | 1 |

```text
失误率 = clamp(9% - 12%×edge(进攻方持球创造, 防守方外线限制)
              - 装备/技能的失误率减免, 2%, 18%)

命中率 = clamp(出手基础命中率
              + 22%×edge(attack, guard)
              + 8%×edge(进攻方持球创造, 防守方外线限制)
              + 明确写明的命中率/关键球特效
              - 防守方明确写明的命中率压制, 16%, 79%)
```

先判失误，再判命中。未命中或失误后交换球权；命中按区域记分后也交换球权。这一版不引入进攻篮板、犯规、罚球或额外阶段积分，保持单挑流程清晰。所有效果都在战报中注明来源，命中率限幅保留偶然性。

三种出手按基准命中率计算的单次进攻期望得分分别约为：外线拉开 0.55、突破冲筐 0.53、护框收缩 0.53（未计失误、战术增减和攻防差）。三分得 2 分，因此其基准命中率需低于中近投；正式数值仍以模拟对战校准。

## 7. 技能、羁绊和装备迁移原则

原技能和羁绊的六项属性效果已映射为五维效果，卡片说明与详情由新效果生成。映射关系：

| 原效果意图 | 新目标层示例 | 说明 |
| --- | --- | --- |
| 三分、远投 | 投射威胁；少数招牌技能可专门提高三分出手强度 | 投射维度也影响中投，纯三分技能要写明专属触发 |
| 中投、急停 | 投射威胁与持球创造，或中投出手强度 | 与纯三分射手区分 |
| 突破 | 持球创造与禁区终结 | 既影响过人，也影响近筐出手 |
| 控球 | 持球创造、失误率或经济 | 经济技能不应伪装成属性增益 |
| 篮下 | 禁区终结、护框强度 | 进攻型内线与护框型内线分别设计 |
| 防守 | 外线限制、护框强度 | 锁外线与守禁区可分路线 |
| 全属性 | 五维共同增益，按其覆盖广度降低百分比 | 不回写球员六项卡面属性 |

A/B/C 的基础模板先按槽位职责迁移，S 和 SSR 逐卡复核：保留既有球员身份、触发槽和经济特色，再决定对五维、特定出手或失误的具体作用。羁绊数值需与新战斗维度统一标价，经济型羁绊继续以战力预算折抵。装备和临时强化只加五维或本场特效；所有已穿装备直接作用于融合球员，不要求某名球员或特定槽位在阵。一次效果只能属于一个明确的层，避免同一加成同时提高基础属性和战斗维度。

## 8. 对手、胜负与战报

对手仍是**单名球星**，以其六项属性构造等效六槽评分和五维；不能把敌方设计成六人阵容。敌方和我方使用同一回合公式。当前使用 [50 关对手名单](opponent-roster.md)：保留各球员基础属性的强弱差异，前十关按 `50 + (关卡 - 1) × 2.5`、第 11–50 关按 `72.5 + (关卡 - 10) × 1.7` 校准目标五维均值。第 51 关起循环七名 SSR，每轮升一星直至五星；五星后继续增加属性，保持强度上升。每名球员有固定风格倾向，赛前界面隐藏，战斗照常计算。

获胜条件保持现有规则：任一方达到 **11 分且领先至少 2 分**即结束；达到 **15 分**时由领先方获胜。继续保留安全回合上限，若到上限仍未决出胜负，先比较比分，再比较双方本场五维综合强度，最后使用固定种子决定，保证不会死循环且同种子可复现。

赛前展示双方五维和战术倾向；战后保留最终比分与关键回合，记录出手类型、失误、命中和战术克制。融合面板继续显示六张卡的槽位与培养信息，并新增独立的五维区域。界面必须明确分开“球员属性”“槽位评分”“融合体战力”，避免玩家把百分比技能误认为卡面属性增长。

## 9. 首版接入与平衡结果

球员技能、80 组羁绊、装备、临时强化、策略和开局天赋已接入五维结算。备战界面展示六项融合属性和五项单挑战力，球员详情展示升星与训练后的六项属性。存档结构中的球员、羁绊和装备 ID 没有改变。

旧十人对手序列在调低开局 A/S 概率后，固定招募、训练和克制策略下，200 个种子中有 **145 局**通关前十关，接近改动前同策略约 147 局。此数据**不代表当前 50 人对手序列**；新序列的多种阵容、策略和无尽关卡仍需重新校准。自动测试验证了技能、羁绊、装备、强化和策略不更改六项融合属性，升星和训练会更改。
