# 开局天赋：17 条篮球融合路线

开局天赋共 **17 条，10 条默认、7 条生涯解锁**，覆盖经营、招募、养成、羁绊、战术和决战等取舍方向。所有效果均作用于篮球游戏现有的六项属性、五项单挑战力、11 分制对战与奖金循环。

每局从已解锁池随机展示 3 条，选择 1 条并持续整局。旧版 5 条天赋仅用于兼容已有存档，不再进入新局候选池。

## 结算和显示规则

- 天赋不会直接修改球员的基础六项属性。球星工坊、发展联盟只改变**升星和训练之后**的六项成长；其余战力效果进入五维。
- 招募概率面板显示实际天赋加权后的 S 概率和 SSR 每组概率。SSR 仍按每组独立判定。
- 折扣和加价会同时用于商店按钮、余额判断和扣款。免费装备刷新显示“免费刷新”，用完后恢复正常刷新价。
- 开局随机装备从对应级别的通用/位置装备中抽取；球衣由商店购买并进入球衣收藏。
- 有胜利恢复效果时，士气在本场结算后恢复；失败仍正常扣 1 点士气。每关整备奖金在进入下一关时发放。
- 生涯解锁根据已保存的结算局数、胜场、最高关卡和已发现球星即时判定，不消耗传奇点。
