# 传奇装备与球衣商店调整

## 本次变化

- 新增10件非球衣传奇装备：头带、护腕、球鞋、戒指、战术板各2件，每个部位1件A级、1件B级。完整装备库由52件增加至62件。
- 点数商店合并为“传奇商店”页，包含球衣与装备两种解锁入口；球衣500传奇点、装备300传奇点，均随机、不重复。下方不展示解锁收藏列表，获得内容仍通过弹窗确认。
- 解锁只开放后续新开局的装备池，不直接发放本局装备，也不上传解锁请求；解锁记录保存本地，开局/最终成绩验证包含解锁花费。
- 新开局的商店前三栏只抽五个非球衣部位，部位不重复；球衣单独判断是否追加为第四栏。没抽到球衣则只显示三栏。
- 老对局继续按原规则运行，原球衣解锁与收藏保留。

## 结算细节

- 胜利奖金仅胜利生效，失败补偿仅失败生效；每场奖金对胜负都生效。战术克制奖金仅在策略克制成立时获得，沿用现有克制规则。
- 折扣仅佩戴普林斯顿战术板时生效，对购买装备报价有效，最低1奖金；不会降低刷新费用或点数解锁费用。
- 潮流戒指每累计5场佩戴期间的胜利恢复1点士气，失败不计入。暂停佩戴时停止累计，重新佩戴继续此前计数，计数随存档保存。LeBron 22只提供突破+9、防守+4，不提供回血。
- 更衣室收藏区以滑块切换“装备收藏／球衣收藏”。同部位不同装备可购买，无需出售或替换，槽位已占用或装备栏满时自动放入收藏；相同装备ID不重复购买。
- 点击收藏装备的“装备”会与同部位当前装备交换，原装备进入收藏，不收取费用、不自动出售。普通装备只在装备后生效，未装备的收藏装备不叠加数值、经济或回血效果；球衣保留全部收藏生效机制。收藏装备可独立出售。
- 逆风复苏头带属性为防守+6、控球+2；佩戴时若对局或事件失败使生命归零，恢复至1点并消耗装备，阻止本次死亡结算。卸下或消耗后不再保命。
- 装备付费刷新在每关依次为3、4、5……奖金，不设10点封顶；免费刷新不增加付费计数，进入下一关重新从3开始。刷新计数随本局存档保存。旧版对局保持原刷新价格。
- 装备回血允许突破基础3点，与现有回血效果共享总士气13上限，显示仍为3/3 +溢出值。多件回血装备可分别累计，达到上限的恢复不额外储存。
- 未解锁装备不会被商店或新规则开局赠装抽到。新解锁不会追溯加入正在进行的对局。

## 球衣第四栏概率

每次装备池生成或刷新，球衣第四栏以独立固定 **15%** 概率出现，不受非球衣装备品质、传奇装备解锁数量或已持有装备影响。

判定成功后，从已解锁、满足阶段条件且尚未拥有的球衣中等概率抽取一件；没有可购买球衣时，不追加第四栏。前三栏仍只抽取非球衣装备，沿用单件权重 C=84、B=45.6、A=6、S=1，不改变原有品质概率。

## 上线说明

新开局使用规则版本5，云函数同时接受规则版本1～5，已有规则版本4对局保留原装备池和随机序列。前端、云函数装备数据与结算代码同步更新；新增解锁记录和回血计数使用已有JSON存档字段，不需要新增数据库表。

发布前需部署本次activity_api云函数，再发布前端；仅发布前端会使版本5开局无法获得云端成绩验证。构建不会自动部署云函数。

# 装备收藏容量与样式补充

- 未装备的非球衣装备默认可收藏5个；已装备物品、球衣不占此容量。
- 天赋加成新增「装备收纳」，共5级，每级容量+1，最高10个。各级价格为180、350、600、900、1300传奇点；购买后从新开局生效。
- 收藏满时，需要存入收藏的装备不可购买，也不会扣奖金；出售收藏装备后释放容量。收藏内换装不额外占位。
- 旧存档超出容量的物品保留，不能继续超额购买；存档恢复保留本局容量。
- 点数商店入口改为柔金渐变，收藏卡片名称和部位文字与已装备栏保持一致。
- 本次新增局外加成需要同步更新云函数中的游戏规则文件，供排行榜校验识别。
- 第5版对局单场胜利总奖金最高90，包含基础奖金、阵容收入、利息及羁绊、技能、装备、天赋的战后奖励；达到封顶时结算明细提示上限。历史规则对局保留原结算方式。
