# 6 融合位 + 10 备战位：纯战力最强阵容攻略

更新日期：2026-10-09。

## 计算口径

- 使用正式 `game-core.js` 的球员属性、槽位权重、技能、羁绊和 OVR 公式。
- 118 张球员卡均可选；6 个融合位与 10 个备战位，共 16 张不同 ID 的卡。
- 统一三星、训练三级，这是主线共同的养成上限。备战席已扩容到 10。
- 不计装备、临时强化、永久升级、开局天赋战力加成或战术加成；测试用长期合同保持战力中性。
- 只最大化面板 OVR，不将回血、奖金、免费招募、获取难度或胜率计入评分。
- 先排除本次新增的三条回血羁绊计算；完成更新后再复算，确认结果没有降低。
- 无尽训练上限随关卡变化，因此没有脱离关卡、星级和训练等级的单一“绝对最高数值”。本攻略的最优结论仅适用于上述条件。

## 为什么可以证明达到最高值

目前球员技能和羁绊所在的五维加成层最高为 +40%。不计装备、开局战力加成和战术时，每个战力维度最多是其基础值的 1.4 倍。

基础五维平均值可以展开成六个槽位评分的加权和。对六个不同 ID 的首发，枚举每个位置评分最高的六名候选就足够：若使用第七名或更低，最多只有五名更优候选被其他位置占用，总能找到一个未占用的更优替代。

计算程序完整枚举这一候选集合中的合法分配，得到基础战力最大值 182.087；乘以 1.4，理论上界为 **254.9218**。推荐阵容调用正式 `C.fused` 得到同一数值，达到理论上界，误差仅为浮点运算精度。

这是一个达到最高值的阵容，**不是唯一最强解**。这组六名 SSR 的技能已使五维加成全部达到 +40%，许多备战组合会得到相同 OVR。上述备战席兼顾现有羁绊、换位候选与新增续航，但没有额外提高已封顶的 OVR。

## 实际组队顺序

1. 先完成六个融合位，再补充备战和扩容；不要为追求最终名单让前期融合位空缺。
2. SSR 未获得时使用对应基础球员暂代：库里、杜兰特、詹姆斯、魔术师、奥尼尔、邓肯。
3. 优先补克莱、格林、伊戈达拉，形成勇士相关组合；再补魔术师、贾巴尔、伯德等现有羁绊成员。
4. 持有本攻略全部卡后，将训练资金优先投入六个 SSR 融合位，替补无需为凑羁绊专门训练。

上述顺序是经营建议，不是证明过的最省资金或最高通关率策略。

## 复算方式

```powershell
node scripts/calculate-strongest-roster.cjs --baseline

```

`--baseline` 仅在计算进程内排除新增回血羁绊，不修改游戏文件；不带参数使用全部当前羁绊。结果写入 `.local-tools/strongest-roster.json`，包含首发、备战、五维、实际 OVR、理论上界和最优性核验结果。

## 加成机制的后续优化建议

此次计算说明：现有 SSR 整体加成很容易覆盖五维，使大量羁绊只剩经济意义。建议先做以下设计验证，再决定改公式：

1. 将技能、羁绊、装备、开局天赋与战术的原始加成和实际生效值分别展示，标注递减或封顶状态。
2. 把当前硬截断改为合并后的平滑递减，避免 +40% 后完全失效。例如 0～30% 全额、30～60% 半额、60% 以上四分之一生效；负面效果保持独立可读。
3. 明确不同加成层的顺序，避免两个 +40% 分组相乘导致 +96%，但同组后续投资完全无收益。
4. 先降低 SSR 的通用全维覆盖，保留岗位专精；让羁绊提供额外战力空间和续航、经济等独立功能。
5. 调整后重新计算最强阵容，并用相同种子检查主线和无尽胜率，避免只抬玩家数值却破坏敌军坡度。

本节为建议，本次没有修改五维叠加公式。
