# 无浏览器模拟器小样本一致性验证

首轮实现直接复用游戏真实核心和事件系统，正式数值未修改。此批数据用于验证流程、复现和记录能力，不作为平衡性定论；尚未执行1000局研究或生成最终 BALANCE_REPORT.md。

## 已实现

- 5类玩家策略；独立游戏种子、AI种子与开局候选种子。
- 合法整局流程、真实经济、训练、满员处理、换位、商店、装备、强化、战斗、事件与续关。
- 明确标记的指定起始关卡和预设阵容场景，不混入自然成长数据。
- 逐操作状态哈希、随机状态、资源、阵容、战斗五维、事件和完整核心状态记录。
- 单局、批量、失败回放、浏览器全局模块加载与云端验证器的交叉验证。
- 关卡、战斗次数、操作次数、时间上限；独立worker超时防护，截尾与死亡分开。

## 验证条件

执行 `node balance/cli.cjs smoke --count 20 --out artifacts/balance/smoke-20261010-final`。五类策略各4局，共用10001～10004四个游戏种子；默认全新账号、无广告、最高30关、单局30秒。天赋只能从本局候选中选择，正常对局没有添加奖金、球员、装备或属性。

最终批次共20局、3254次操作、281场战斗、77次事件结算。21种事件实际出现，16次事件判定失败。全部20局的浏览器全局加载回放、逐操作云端核心回放和战斗前序操作的云端验证通过；0个引擎错误，0个时间/操作上限截尾。

17局正常死亡，3局通关30关后按关卡上限截尾。截尾局是高手10001、极限10001、普通10002，不能记为在30关失败。

| 玩家策略 | 每个种子的最高尝试关卡（10001/10002/10003/10004） | 30关截尾局 |
| --- | --- | ---: |
| 随机 | 2 / 3 / 2 / 2 | 0 |
| 新手 | 5 / 8 / 8 / 2 | 0 |
| 普通 | 7 / 30 / 11 / 2 | 1 |
| 高手 | 30 / 28 / 8 / 5 | 1 |
| 极限有限搜索 | 30 / 12 / 29 / 4 | 1 |

上述表格是实际执行结果，每种策略只有4局，不能据此推断真实用户平均水平、全局最强构筑或长期存活率。极限策略目前搜索已知招募/装备后的下一步换位，不保证比所有启发式策略更强。曾发现搜索重复计算导致时间截尾，已减少无效分支并重新执行最终批次；上述数字只取最终批次。

## 回归与复现

新增7项测试：初始化跨浏览器/Node一致性、固定种子完整轨迹、5类策略三路回放、AI信息隔离、上限/非法操作处理、篡改回放拒绝与预设场景、广告条件。最终构建和全项目305项测试通过，0失败；另选高手10004死亡局执行独立CLI回放，45次操作、7场战斗一致。

原始每局记录和汇总留在 `artifacts/balance/smoke-20261010-final/`，不进Git。代码源与工具源SHA-256记录在每局文件内。修改核心或工具代码后，旧记录会拒绝按新实现回放，需要对应代码版本。

