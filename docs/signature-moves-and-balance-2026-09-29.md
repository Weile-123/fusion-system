# 前十关难度与招牌动作（2026-09-29）

## 主线对手

前十关目标战力由 `50、54、56、58、61、65、72、80、88、96` 调整为 `64、70、78、86、90、92、94、96、99、103`。第 11 关后的凸曲线以第 10 关战力为起点，避免进入无尽时倒退。对手身份和战术顺序不变。

使用 `node tests/flow-audit.cjs <policy> 1000 10` 对相同 1,000 个种子模拟：

模拟轮流使用现有 17 种开局天赋；`openingOnly` 不主动购买装备，但保留天赋自带装备或奖金等初始效果。

| 玩法 | 调整后主线通关 | 说明 |
| --- | ---: | --- |
| `openingOnly` | 25/1000 | 只用开局六人、不消费、不再招募，每关选择克制战术；调整前为 241/1000 |
| `noGrowth` | 108/1000 | 后续继续招募与换位，不训练、不买装备 |
| `advanced` | 171/1000 | 继续招募、换位，按固定顺序训练和买装备 |
| `noTraining` | 241/1000 | 继续招募、换位并买装备，不训练 |

`openingOnly` 在第 1–5 关的过关率依次为 99.4%、96.9%、88.6%、67.5%、70.5%。模拟允许失败后消耗士气重试。固定顺序的 `advanced` 仍弱于 `noTraining`，说明训练和装备的消费顺序还需要单独校准，不能仅通过抬高敌人属性解决。

## 招牌动作

六个融合位置产生六种候选招牌动作。每场按照相关两个位置的评分，自动选出最强的一个进攻动作和一个防守动作。装备加成不参与选择，换位与训练会影响选择；不增加比赛中的手动决策。

| 动作 | 位置 | 效果 |
| --- | --- | --- |
| 变向后撤步 | 三分＋控球 | 触发时三分命中 +10 个百分点、失误 +2 个百分点 |
| 横移晃投 | 三分＋中投 | 横移晃开防守后，三分出手占比 +8 个百分点；触发时命中 +6 个百分点 |
| 急停跳投 | 中投＋突破 | 触发时中投命中 +10 个百分点 |
| 对抗终结 | 突破＋篮下 | 触发时篮下命中 +10 个百分点 |
| 预判抢断 | 防守＋控球 | 触发时对手失误率 +6 个百分点 |
| 追身封盖 | 防守＋篮下 | 触发时对手篮下命中 -10 个百分点 |

动作只在对应回合自动触发，每场每种最多两次，两次触发至少间隔三个本方或对方回合。相关位置的球员每有一人至少训练一次，对该动作的命中率或失误率效果再增加 2 个百分点。阵容与赛前页展示已选动作，战报展示触发次数和关键回合。
