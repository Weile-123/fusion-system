# 随机徽章系统

2026-10-11本地实现，徽章系统从规则7启用，当前新局使用规则9，尚未部署线上。徽章内容以[完整徽章库](完整词条库.md)为准，共112条，1—5星分别为11、18、27、31、25条。游戏内名称统一为“徽章”；文档路径及存档字段保留兼容入口。

规则9“冠军红利”调整为4星，仍为胜利奖金+3，不再进入5星广告自选或满星天赋5星补授池；已有该徽章的规则9测试存档保留原编号并显示4星。规则7—8保存旧5星归属及抽取顺序，以兼容历史对局。

## 获取与操作

- 每名球员首次出现在本局招募候选时分配第一条并展示；1—5星各20%，同星级内均匀抽取。候选再次出现不重抽，重复招募不重抽，出售后重新招募保留。
- 球员达到当前星级上限时追加第二条，仅从3—5星抽取。两条不能同名。
- 规则8的“巨星传承”天赋在满星时额外补授随机5星第三条，每局每名球员仅一次，三条互不重名；补授槽不能重随或广告替换，出售重招、无尽再次满星不重复补授。普通天赋仍最多两条。
- 融合面板及备战席的球员详情可重随；招募卡详情仅展示徽章，即使已拥有该球员也不提供重随及广告自选按钮。每名球员每槽本局至多3次，分别消耗10、30、50奖金。第一槽从1—5星抽取，第二槽从3—5星抽取，排除该球员当前持有的全部徽章。
- 普通徽章槽可不限次数观看广告自选5星徽章，每次需完整观看成功。候选排除该球员已持有徽章；确认后替换，取消保留原徽章，广告失败或超时不进入自选。满星补授的第三槽仍不能替换。
- 战斗结果待处理、招募待替换、随机事件处理中、对局结束时不能重随或进入自选。自选期间暂停其他对局操作，可以确认或取消。

招募卡采用各稀有度的金属材质，SSR沿用钻石配色。左上稀有度与右上球探值使用同套粗斜体字体、对应等级的纵向渐变色。卡片高度固定；已有球员只显示升星提示，不显示羁绊，十连中的重复升星卡同样处理。新球员的羁绊提示居中排列，最多三条，完整显示名称和当前／所需人数，已组成的羁绊也显示人数。底部左侧展示固有技能名，右侧随机徽章使用同框彩色标签，星级以对应数量的星星展示，详情通过“查看详情”按钮进入。本地测试弹窗的“查看招募卡片”展示10张独立模拟卡，覆盖C/B/A/S/SSR、升星、多条羁绊与1—5星徽章；预览不改变当前对局、不保存、不上传。

本地开发测试面板提供“免广告”开关，默认关闭。开启后点击游戏中的广告按钮直接模拟完整观看成功，支持天赋自选、S级招募、徽章5星自选与死亡恢复；核心资格及次数限制不变。关闭恢复原SDK，刷新页面恢复关闭状态。此功能只在开发环境加载，正式发布包不包含免广告模块，测试存档和云端仍相互隔离。

## 生效与结算

融合面板卡片不直接展示随机徽章，点击球员详情查看徽章与效果。备战席满员时，直接出售待处理的 SSR 新球员需要二次确认，取消不改变对局；其他等级直接出售。十连招募中的每名待处理 SSR 分别确认。

融合面板六人满编且携带者在面板时生效，备战席不生效，不要求携带者在指定位置。能力加成合入原五维加成与软上限；概率修正继续受原命中、失误上下限约束。奖金、折扣、免费刷新、战术和恢复士气按徽章说明执行。

开战时固定本场徽章；每轮徽章奖金按每次战斗结算发放，胜负均生效，同关重试可以再次获得；同类免费刷新徽章不叠加，失败后返回备战恢复该免费次数。恢复士气按徽章编号共享计数，同名徽章的每个上阵携带者在胜利时各推进一次；无人携带上阵时暂停，出售、重招或重随不清除累计记录，不设本局恢复次数限制，总士气最高13。旧本地存档中按球员记录的恢复计数在恢复时合并到共享计数。

## 存档与云端兼容

本局记录球员徽章、招募预览、各槽重随次数、自选使用历史、未完成的自选弹窗、恢复计数及关卡领取标记；规则8另记录补授槽位。历史自选标记不限制后续广告，刷新后可继续未完成的选择。恢复存档不重新抽取，不额外推进随机种子。规则1—6不启用新系统，规则7保留原天赋和最多两槽；已有徽章测试存档同样取消广告次数限制，对手曲线仍按原规则运行。

服务端使用相同徽章表与核心，并校验、重放重随、进入自选、确认、取消四类操作。徽章状态沿用现有对局JSON字段，不需要新增数据库表。当前开局天赋“场外协助”按发现事件数解锁，需要先应用 `20261011210000_event_talent_unlock.sql`，以补充云端生涯事件汇总。广告调用沿用现有平台奖励广告接口；功能测试使用模拟回调，真实广告仍需在平台环境验收。

发布顺序为先部署支持当前规则9的后端，再上线前端。规则9仅调整新局对手数值，徽章与天赋沿用规则8；线上后端若尚未支持规则9，直接上线当前前端会导致新局云端校验失败。准备好的本地后端保留规则1—8支持，不改变历史周榜记录。
