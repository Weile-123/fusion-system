# 随机词条系统

2026-10-11本地实现，词条系统从规则7启用，当前新局使用规则8，尚未部署线上。词条内容以[完整词条库](完整词条库.md)为准，共112条，1—5星分别为11、18、27、30、26条。

## 获取与操作

- 每名球员首次出现在本局招募候选时分配第一条并展示；1—5星各20%，同星级内均匀抽取。候选再次出现不重抽，重复招募不重抽，出售后重新招募保留。
- 球员达到当前星级上限时追加第二条，仅从3—5星抽取。两条不能同名。
- 规则8的“巨星传承”天赋在满星时额外补授随机5星第三条，每局每名球员仅一次，三条互不重名；补授槽不能重随或广告替换，出售重招、无尽再次满星不重复补授。普通天赋仍最多两条。
- 融合面板及备战席的球员详情可重随；招募卡详情仅展示词条，即使已拥有该球员也不提供重随及广告自选按钮。每名球员每槽本局至多3次，分别消耗10、30、50奖金。第一槽从1—5星抽取，第二槽从3—5星抽取，排除该球员当前持有的全部词条。
- 每名球员每槽有一次广告自选5星机会。广告成功后展示5星候选，排除已持有词条；选择、查看效果并确认替换后才消耗机会，取消不消耗。广告失败或超时不进入自选。
- 战斗结果待处理、招募待替换、随机事件处理中、对局结束时不能重随或进入自选。自选期间暂停其他对局操作，可以确认或取消。

招募卡采用各稀有度的金属材质，SSR沿用钻石配色。左上稀有度与右上球探值使用同套粗斜体字体、对应等级的纵向渐变色。卡片高度固定，升星和羁绊组成在顶部居中并留边距，羁绊最多显示三条，重复球员也展示当前羁绊组成。底部左侧展示固有技能名，右侧随机词条使用同框彩色标签，星级以对应数量的星星展示，详情通过“查看详情”按钮进入。本地测试弹窗的“查看招募卡片”展示10张独立模拟卡，覆盖C/B/A/S/SSR、升星、多条羁绊与1—5星词条，包含SSR升星与羁绊同屏示例；预览不改变当前对局、不保存、不上传。

## 生效与结算

融合面板卡片不直接展示随机词条，点击球员详情查看词条与效果。备战席满员时，直接出售待处理的 SSR 新球员需要二次确认，取消不改变对局；其他等级直接出售。十连招募中的每名待处理 SSR 分别确认。

融合面板六人满编且携带者在面板时生效，备战席不生效，不要求携带者在指定位置。能力加成合入原五维加成与软上限；概率修正继续受原命中、失误上下限约束。奖金、折扣、免费刷新、战术和恢复士气按词条说明执行。

开战时固定本场词条；每轮词条奖金按每次战斗结算发放，胜负均生效，同关重试可以再次获得；同类免费刷新词条不叠加，失败后返回备战恢复该免费次数。恢复士气按词条编号共享计数，同名词条的每个上阵携带者在胜利时各推进一次；无人携带上阵时暂停，出售、重招或重随不清除累计记录，不设本局恢复次数限制，总士气最高13。旧本地存档中按球员记录的恢复计数在恢复时合并到共享计数。

## 存档与云端兼容

本局记录球员词条、招募预览、各槽重随次数、自选使用状态、未完成的自选弹窗、恢复计数及关卡领取标记；规则8另记录补授槽位。恢复存档不重新抽取，不额外推进随机种子。规则1—6不启用新系统，规则7保留原天赋和最多两槽，已有旧局继续按其原规则运行。

服务端使用相同词条表与核心，并校验、重放重随、进入自选、确认、取消四类操作。词条状态沿用现有对局JSON字段，不需要新增数据库表。当前开局天赋“场外协助”按发现事件数解锁，需要先应用 `20261011210000_event_talent_unlock.sql`，以补充云端生涯事件汇总。广告调用沿用现有平台奖励广告接口；功能测试使用模拟回调，真实广告仍需在平台环境验收。

发布顺序为先部署支持当前规则9的后端，再上线前端。规则9仅调整新局对手数值，词条与天赋沿用规则8；线上后端若尚未支持规则9，直接上线当前前端会导致新局云端校验失败。准备好的本地后端保留规则1—8支持，不改变历史周榜记录。
