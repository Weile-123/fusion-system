# 完整徽章库

本表包含112条篮球徽章，按融合球员、半场单挑、战术、奖金与士气机制设计效果，分为1—5星。名称参考NBA 2K徽章的命名风格，与各条效果对应。从规则7接入，当前新局使用规则9，尚未部署线上；获取、重随及天赋额外补授规则见[随机徽章系统](随机词条系统.md)。

名称采用动作、打法、角色称号和篮球经营主题，例如“运球投篮高手”“关键先生”“禁区守门人”“装备赞助商”。这些是本游戏的徽章名，并非NBA 2K官方中文徽章名称；名称不新增隐藏效果，具体加成以表内说明为准。

## 统一生效规则

- 徽章携带者必须位于六个融合位置之一；备战席不生效。能力、命中、失误和战术效果作用于最终融合球员，不直接改写携带球员的六项基础属性。
- 所有效果仅本局有效；一次战斗开始时固定本场生效徽章，结算奖金和累计胜利恢复士气均按开战时的携带者与徽章判定。
- 百分比能力加成进入现有五维加成汇总，超过30%的部分折半增长。例如其他来源+30%、徽章再+10%，最终该维度倍率增益为+35%，不是额外独立乘10%。“全能力”指投射威胁、禁区终结、持球创造、外线限制、护框强度。
- “命中率/失误率增加或减少N个百分点”是概率修正，不是OVR增益。命中率仍限制在16%—79%，失误率仍限制在2%—18%；关键分指任意一方比分达到8分后的回合。
- 每轮奖金在每次战斗结算时发放，胜负均生效，同关重试也可获得；失败后重新进入备战恢复徽章免费刷新次数。主线第10关及最终死亡等终局结算也应结清已满足条件的徽章奖金，不能因缺少下一关而漏发。
- 装备折扣与现有折扣一起计价，最终购买价格最低1奖金。免费刷新徽章多名携带者持有时只增加一个额外次数；可与开局天赋提供的免费次数相加。
- 恢复徽章按编号共享胜利计数。同名徽章每个上阵携带者各推进一次该计数，达到胜场间隔后恢复士气；无人携带上阵时暂停，换位、出售、重招和重随不清零。可突破初始3点，总士气最高13，不设本局累计恢复次数限制，达到13点时不储备恢复。
- 每场胜利结算总奖金遵循当前90上限。首次获取1—5星各20%；满星追加徽章和第二槽重随仅从3—5星抽取，各占三分之一。已完成三档各100局正常游玩测试及关卡微调，详见[关卡微调报告](../balance/2026-10-11-关卡微调/关卡微调报告.md)。

共112条：1星11条、2星18条、3星27条、4星31条、5星25条。后续直接在本表修改，并运行徽章生成脚本同步正式数据。
