# 开局天赋

这份文档是你直接修改开局天赋的编辑入口。2026-10-11按你的修改实装到本地规则8，共20条（默认12条、需解锁8条）。前后端已同步，尚未部署线上；规则1—7的旧局继续使用原天赋配置。

## 如何修改

直接修改每条天赋的“名称”“分类”“加成”“代价”和“解锁条件”。只改加成时，其余字段保留即可；没有代价写“无”。需要新增触发规则、词条补授或事件效果，也直接用中文写清楚。

“当前实现细节”用于理解现有效果，不是额外的待编辑配置；若新加成与旧细节不一致，实装时以你修改后的设计为准并更新细节。建议明确“每场/每轮/每关”、是否胜负均生效、次数上限，以及加百分比还是加百分点。编号用于关联存档，请保留。修改文档本身不会立即改变游戏；你完成修改后告知我，我会检查并实装前后端、旧局兼容和必要功能验证。

解锁条件同时列出多项时，需要全部满足；局外已解锁记录也可直接开放。数值调整不自动执行此前暂缓的低、中、高各30局模拟。

## 本次实现细节

- 当前规则9仅微调新局对手数值，天赋及词条沿用规则8；规则1—8已有对局保留原数值曲线。
- 规则9三档各100局验证后，通过关卡中位数为低阶12.5、中阶25、高阶65关，均位于旧版与未微调新版之间。详见[关卡微调报告](../balance/2026-10-11-关卡微调/关卡微调报告.md)。
- 装备返款：先检查并支付全额实付价格，再返还实付金额的10%，不足1奖金的部分向下取整；购买、替换装备均生效，重复点击不会重复返款。
- 发展联盟：训练费用乘1.5后向上取整，最低1；普通卡每级训练3%→4.5%，SSR为4%→5.5%。原来的训练减价、出售溢价和付费招募加价取消。
- 巨星传承：普通满星第二条仍从3—5星抽取，再补授额外5星第三条；同角色去重，补授每局每名球员仅一次，出售重招或无尽再次满星不重复补授。第三槽不能重随或广告替换。
- 豪华轮换：激活羁绊的五维收益乘1.3；奖金、免费次数和恢复量乘1.3后向下取整，恢复间隔保持不变。初始容量+3，取消原来额外扩容上限+3；已有超上限存档仍保留。
- 场外协助：成功率100%仅保证出现后的事件挑战成功，不保证事件必定出现，不免除费用、装备收纳等条件。永久属性奖励乘1.5，包括稳妥练习；装备、球衣、奖金和生命奖励不乘1.5。战后收入-2胜负均生效，失败补偿另减2，因此失败合计少4奖金。
- 场外协助解锁：保留无尽第13关条件，将累计40胜改为发现至少10种不同事件。重复事件不重复计数；云端按已结算且校验通过的历史对局汇总。发布前应用 `20261011210000_event_talent_unlock.sql`，再部署云函数与前端。
- 巨星传承的新解锁条件只约束未解锁的新玩家；已有完成对局的旧玩家保留旧版默认开放资格。
- 功能验证覆盖新机制、事件解锁与数据库汇总、详情操作、存档恢复和云端回放；规则1—7的140组开局、招募和战斗结果与修改前保持一致。
- 已完成旧、新版本各档100局同种子正常游玩，共600局，无执行错误或截断。高阶积极观看奖励广告，低、中阶不看广告，上个版本的难度曲线页面及原始文件保持不变。详见[数值对比报告](../balance/2026-10-11-词条天赋更新/数值对比报告.md)与[新旧曲线](../balance/2026-10-11-词条天赋更新/index.html)。
