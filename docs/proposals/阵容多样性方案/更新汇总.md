## 2. 加成公式

每个战力百分比层单独计算：

```text
加成≤30%：正常生效，最低为−30%
加成>30%：实际加成＝30%＋（加成−30%）×50%
最终属性＝max(0,（基础＋固定值）×（1＋常规层实际加成）×（1＋开局层实际加成）)
```

例如累计加成60%，实际生效45%。保留当前常规层、开局层分别计算的顺序，装备对位置属性的百分比加成也采用相同递减。

星级、训练成长不套用此递减。SSR成长仍按加法计算：`基础×[1＋(星级−1)×20%＋训练等级×4%]`，三星、三级训练为1.52倍。经济收益、回血不套用战力公式；敌方数值曲线独立调整。
